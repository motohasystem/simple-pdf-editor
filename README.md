# Simple PDF Editor

HTMLファイル1つで動くシンプルなPDFエディタです。ブラウザで `index.html` を開くだけで使えます（pdf.js / pdf-lib をCDNから読み込むためネット接続が必要）。

## 機能

- テキスト入力（複数行、ゴシック／明朝、サイズ・色指定）
- チェックマーク等の記号（✓ ✗ ○ ●）をクリックで配置
- 押印用の透過PNG画像の貼り付け（ファイル選択またはページへドロップ、幅はmm指定）
- ドラッグで移動、右下ハンドルで拡大縮小、矢印キーで微調整、Deleteで削除、Ctrl+Zで元に戻す
- GETパラメータによる文字・画像の差し込み

## GETパラメータ

座標の単位はpt（1mm ≒ 2.835pt）、原点はページ左上、y は下向きです。画面下部にカーソル位置の座標が表示されます。

| パラメータ | 内容 |
| --- | --- |
| `t=頁,x,y,サイズ,文字列` | テキストを挿入（複数指定可）。サイズ省略時は `size` の値。文字列中のカンマはそのまま使えます |
| `pdf=URL` | 起動時に読み込むPDF（同一オリジンまたはCORS許可が必要） |
| `img=頁,x,y,幅,URL` | 画像（印影など）を挿入。幅はpt、高さは縦横比から自動 |
| `size` / `color` / `font` | テキストの既定値（例：`size=10.5`、`color=cc0000`、`font=mincho`） |

文字列中のエスケープ：`\n` 改行、`\t` タブ、`\\` バックスラッシュ

```
index.html?pdf=form.pdf&t=1,120,150,12,山田 太郎&t=1,120,180,,東京都千代田区\n丸の内1-1-1
```

値に `&` `#` `+` `%` を含む場合はURLエンコードしてください。画面の「URL生成」ボタンで、現在のテキスト配置から差し込み用URLを作成できます。

## 注意

- 保存時、テキストは日本語フォントを埋め込まずに済むよう高解像度PNG（360dpi相当）として貼り付けます。保存後のPDFでは文字の選択・検索はできません。
- 記号はベクター図形として書き込まれます。
