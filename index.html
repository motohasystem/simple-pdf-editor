PDFをドロップ、または「PDFを開く」

テキスト入力・チェックマーク・印影（透過PNG）の貼り付けができます。

URLのGETパラメータで文字を差し込めます（右上の「?」参照）。

—

差し込み用URL

現在のテキスト（位置・サイズ・内容）を t パラメータに書き出しました。色・書体は全体指定（color / font）のみ反映されます。

使い方

ツールを選んでページをクリックすると配置します。配置済みの要素はドラッグで移動、右下の□で拡大縮小、ダブルクリックでテキスト再編集。 矢印キーで1pt（Shift併用で10pt）移動、Deleteで削除、Ctrl+Zで元に戻す。PNG画像はページ上にドロップしても配置できます。

GETパラメータ

座標の単位はpt（1mm ≒ 2.835pt）、原点はページ左上、y は下向きです。画面下部に現在のカーソル座標が表示されます。

t=頁,x,y,サイズ,文字列テキストを挿入（複数指定可）。サイズ省略時は size の値。文字列中のカンマはそのまま使えます。
エスケープ：\n 改行、\t タブ、\\ バックスラッシュ
pdf=URL起動時に読み込むPDF（同一オリジンまたはCORS許可が必要）
img=頁,x,y,幅,URL画像（印影など）を挿入。幅はpt、高さは縦横比から自動
size / color / fontテキストの既定値（例：size=10.5、color=cc0000、font=mincho）

例：

index.html?pdf=form.pdf&t=1,120,150,12,山田 太郎&t=1,120,180,,東京都千代田区\n丸の内1-1-1

値はURLエンコードを推奨します（特に & # + % を含む場合）。「URL生成」で現在の配置からURLを作れます。
